# Домашние задания по курсу «Введение в анализ данных»

Репозиторий содержит мои решения домашних заданий 4–10 по курсу **«Введение в анализ данных»**.

Курс посвящён практическому применению методов анализа данных, машинного обучения и статистики: от базовой работы с данными до нейросетей, компьютерного зрения, NLP, вероятностных моделей и статистического анализа.
