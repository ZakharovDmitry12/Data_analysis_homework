## 🚀 Как запустить

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ZakharovDmitry12/Data_analysis_homework.git
   cd Data_analysis_homework
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

4. Откройте нужную папку с домашней работой и запустите `.ipynb`-файл.
